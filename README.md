# Samsung Stock Analysis

Samsung Stock Analysis using Python, Pandas, and Matplotlib.

This project analyzes historical Samsung stock price data from 2022 and visualizes the stock price trend with a 10-day moving average.

## Tools Used
- Python
- Pandas
- Matplotlib

## Features
- Loads stock market data
- Analyzes closing price trends
- Calculates 10-day moving average
- Visualizes stock prices using a line chart
